## Projects

- [relibc-qnx](https://github.com/NikeKhin/relibc-qnx): [relibc](https://gitlab.redox-os.org/redox-os/relibc), the C library written in Rust, for QNX Neutrino 7.1 and 8.0 on AArch64. QNX programs then build with standard Arm toolchains instead of the QNX SDP: Rust nightly with `rust-lld`, and the Arm GNU Toolchain's GCC for C and C++.
- [wasm-micro-runtime-qnx](https://github.com/NikeKhin/wasm-micro-runtime-qnx): the WebAssembly Micro Runtime (WAMR) for QNX, built against relibc-qnx.
